# ContentFlow Neutral Desktop UI 重设计规格

## 目标

将当前以深色紫色、渐变光晕、全页面卡片化为主的通用 SaaS 模板，重做为更接近海外成熟生产力工具的 neutral desktop utility。参考的是 Linear 的信息密度、Raycast 的 macOS 克制感、Attio 的列表与属性层级，以及 Superhuman 的高效操作反馈；不照搬任何单一产品。

重设计只调整信息呈现与视觉交互，不修改工作流规则、Zustand action、数据结构、文件持久化、隐私逻辑或平台数据口径。

## 当前问题

- 紫色渐变 Logo、紫色发光、Copilot 径向渐变和深黑底色叠加，AI 模板感过强。
- 统计、筛选、内容、状态都被做成圆角卡片或胶囊，层级同质化。
- 10px、11px 文本过多，桌面端内容密度高但可读性不足。
- 页面大量使用内联样式，导致按钮、输入、标签、hover 和焦点反馈不统一。
- Dashboard 的 KPI、管道和趋势同权；Kanban 的列、卡片、状态同时着色；VideoDetail 存在卡片套卡和重复标题层级。

## 视觉方向

### 色彩

- 浅色画布：`#f6f6f3`
- 浅色侧栏：`#efefeb`
- 浅色内容面：`#fdfdfb`
- 浅色边框：`#deded8`
- 主文字：`#202124`
- 次文字：`#666b73`
- 行动色：`#3157d5`
- 深色画布：`#141618`
- 深色侧栏：`#111315`
- 深色内容面：`#1b1e21`
- 深色边框：`#30343a`

不再使用品牌渐变、常驻 glow 和大面积紫色。语义颜色只用于状态点、风险、成功和金额状态。

### 排版与密度

- 页面标题：20px / 28px，650
- 区块标题：14px / 20px，600
- 正文：13px / 20px
- 辅助文字：12px / 16px；业务界面不再新增 9–10px 文本
- 关键数字：24px / 28px，tabular nums
- 控件高度：32–34px
- 表格行：保持现有虚拟列表 81px 约束；非虚拟表格 44–52px

### 形状与层级

- 控件圆角 6px，面板圆角 8px，弹窗 12px。
- 胶囊仅用于真正的状态或极短标签。
- 普通 surface 不使用阴影；弹窗、浮层和拖拽卡片才使用阴影。
- 页面优先用边框、分区标题、留白和列表行建立层级，减少独立漂浮卡片。

## 壳层与导航

- 侧栏宽 232px，使用纯色产品标记，不使用渐变与发光。
- 导航按“工作台 / 内容资产 / 经营分析”分组，保持原路由与入口完整。
- 激活态为中性实底 + 细边框 + 蓝色标记，不用大面积品牌色填充。
- 保存状态常驻在侧栏底部，以小状态点表达。
- 主内容区保留独立滚动，页头统一为 72px 左右的内容标题区。

## 共享组件

- Button：主按钮使用行动蓝；次按钮为实底 surface；ghost 只在低优先级动作中使用。
- Input / Select：统一白色或深色 surface、清晰边框、2px 低饱和 focus ring。
- Badge / StatusBadge：减少填充面积，状态点作为第一识别信号。
- Modal：遮罩不使用强 blur；只有 modal panel 使用 elevation。
- EmptyState：图标放入小型中性容器，说明文字提高到 12px。
- Copilot：使用同一套 neutral token，移除径向渐变、渐变徽标和紫色光晕。

## 页面落地

- Dashboard：KPI 合并为一条统计带，避免五张同权卡片；进行中工作放在更高优先级；图表和商单信息保留真实口径。
- Kanban：统一共享页头；列背景更轻，只有状态点着色；卡片改为平面内容条目；保留 dnd-kit、列宽与横向滚动。
- Topics：筛选器改为克制 segmented toolbar，内容面减少 hover 阴影与胶囊数量；所有既有操作保留。
- Scripts：稿件库与编辑器沿用现有结构，统一 surface、输入和文本密度，降低重复卡片的视觉权重。
- Videos：筛选工具栏与表格成为单一工作面；保留虚拟行高、粘性表头、隐私过滤和返回筛选状态。
- VideoDetail：先通过全局 surface、标题与表单层级统一视觉；不触碰商单、平台诊断、隐私和编辑行为。
- Analytics：保持真实导入与计算结果，不强化未接入的分析组件；统一 tab、表格和指标样式。
- Settings：保持全部设置写入行为，视觉上按设置项和分隔线组织。
- DirectorySetup：使用同一品牌标记、排版和按钮系统。

## 验收标准

1. 所有现有路由和操作入口仍可访问。
2. `src/store`、`src/services` 和业务数据结构没有因视觉迁移发生变化；默认主题调整除外。
3. 深色、浅色主题均无紫色 glow 或品牌渐变。
4. Sidebar、PageContainer、Button、Input、Select、Modal、Badge、StatusBadge 视觉一致。
5. Kanban 拖拽、Videos 虚拟列表、Scripts 编辑器高度与各弹窗不被破坏。
6. 商单隐私仍覆盖字段、筛选、搜索、详情、概览和数据分析 surface。
7. 通过测试、类型构建和桌面构建；替换 `/Applications/ContentFlow.app` 后校验安装产物与最新构建一致。
