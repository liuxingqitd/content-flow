# 内容月历多日活动实现规格

## 目标

新增独立的“内容月历”页面，让活动可以覆盖任意连续日期，并保存活动标题、详细信息和外部链接。跨周或跨月活动必须在当前月视图中按周切分为连续条带，而不是只显示在开始日。

## 数据契约

- `CalendarEvent.id`：稳定 ID。
- `title`：必填活动名称。
- `startDate` / `endDate`：必填本地日历日期，格式 `YYYY-MM-DD`，首尾日期均包含。
- `description`：可选活动信息，多行文本。
- `url`：可选 `http` / `https` 链接。
- `createdAt` / `updatedAt`：ISO 时间。
- 活动独立保存到 `calendarEvents.json`；旧目录没有该文件时读取为空数组，首次新增或更新活动时自动创建。

## 交互

- 侧边栏新增“内容月历”入口。
- 月历固定展示完整 6 周、周一到周日；支持上一月、回到今天、下一月。
- 点击空白日期时以该日期作为默认起止日期创建活动；“新建活动”默认使用今天。
- 点击活动条打开详情，可查看完整日期范围、活动信息和链接，并可继续编辑或删除。
- 活动编辑表单校验标题、日期先后关系和链接协议。
- 跨周活动在每周生成一个片段；跨月活动在月历可见范围内裁切，但保存的原始起止日期不变。

## 验证

- 单元测试覆盖月网格、跨周/跨月切片、重叠活动泳道和日期校验。
- 运行 TypeScript 构建、测试和 lint。
- 执行 `npm run desktop:build`，替换 `/Applications/ContentFlow.app`，并校验安装包与构建产物一致。
